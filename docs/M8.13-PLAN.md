# M8.13 Plan — HUD Visibility and Command Help

## Problem

The Swing HUD and Hole HUD cannot be hidden during play, and `/golf help` does not
reflect the current player/operator command surface.

## Decisions

- `H` toggles the two HUDs together, using the existing `minecraft_golf:controls`
  keybinding category.
- `/golf hud` is a permission-free server command that sends a clientbound toggle intent;
  the receiving client toggles from current visibility. HUD visibility is session-only.
  No HUD visibility state is stored on the server.
- A right-click with a golf club reveals both HUDs before swing processing, including
  the no-resting-ball notice path.
- `/golf help` remains concise and player-focused. `/golf help admin` is visible to
  everyone but explicitly labelled OP/GAMEMASTER ONLY; server permission checks on
  commands remain authoritative.
- A regression test enumerates every top-level `/golf` literal and ensures at least one
  help page mentions it.

## Implementation

- Add shared client-only `HudVisibility`, apply it in `SwingHud` and `HoleHud`, and wire
  the H key, server-command/clientbound toggle, and swing-attempt reveal.
- Centralize player/admin help text for reuse by command handlers and the coverage test.
- Update command documentation, changelog, milestone status, and command-registration log.

## Command Routing Regression

The initial Fabric client command registered a partial `/golf` root containing only `hud`.
Fabric 26.2 intercepted sibling commands such as B's `/golf practice ball` and reported
"Incorrect argument for command at position 5: golf <--[HERE]" rather than forwarding to
the server. Use the originally allowed server-command + clientbound-payload fallback.
Remove the client root entirely; add codec and source-boundary regression tests. Manually
check B in practice, B for an eligible tap-in, `/golf help`, `/golf help admin`, and
`/golf hud` after the client and server have both been updated.

No server-side HUD state, persistence, HUD redesign, gameplay changes, or changes to
operator authorization.
