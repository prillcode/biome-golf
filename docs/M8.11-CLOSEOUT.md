# M8.11 — Swing Meter Precision — Closeout

**Status:** Implemented and verified. Shipped in **0.8.5**. Manual meter-feel
playtest remains (see *Remaining boundary*).

## Problem

The three-click accuracy meter could never land exactly in the middle. The private
`SwingController.meterValue` sampled `k / halfSweepTicks` on a triangular wave with
`ACCURACY_HALF_SWEEP_TICKS = 15` (odd), so `0.5` was never a sample. The closest
samples were `7/15 = 0.4667` and `8/15 = 0.5333`, a guaranteed minimum miss of
`1/30`. `ShotResolver` scaled deviation by `|2a − 1|`, so even a visually perfect
click drifted left/right. The HUD marker landed at pixel 74 or 85 of a 160 px bar.

## What Changed

- Added `pro.apdev.biomegolf.club.SwingMeter` — a Minecraft-free, tested triangular
  meter model owning the sweep math and the perfect-band constant. Both the client
  meter and the resolver now share one definition of "perfect".
- `ACCURACY_HALF_SWEEP_TICKS` is now `16` (even), so the centre value is exactly
  reachable at tick 8. Power stays at `24` (already even; `1.0` reachable).
- Added `SwingMeter.PERFECT_BAND = 0.05` and `missMagnitude(accuracy)`. Any click
  within the band of centre produces exactly zero deviation; the remaining spread is
  renormalised so a full miss still reaches the existing `FULL_MISS_FAN_DEG = 14`
  fan. A float-precision epsilon keeps exact band-boundary samples perfect.
- `SwingHud.drawAccuracyBar` now derives the drawn perfect zone from the same band
  (`2 * BAR_WIDTH * PERFECT_BAND` = 16 px) and centres the marker on its value.
- `SwingController` delegates all meter reads to `SwingMeter`.

## Decisions

- Fix is arithmetic (reachable centre) plus a truthful drawn zone, not a change to
  meter speed or the three-click input model.
- `PERFECT_BAND = 0.05` (~16 px green zone) is a small forgiveness increase; it was
  chosen so the drawn zone and the physics agree.
- Full-miss deviation magnitude and left/right sign are unchanged.

## Verification

- `SwingMeterTest`: endpoints, exact centre for even sweeps, periodicity/symmetry,
  `isPerfect` band, `missMagnitude` band edges, power sweep reaches `1.0` and `0.5`.
- `ShotMeterTest`: perfect-band zero deviation for every club; just-outside-band
  fans; full-miss fan preserved to `1e-6`.
- `./gradlew clean test build` passes; no `net.minecraft.client` imports in `src/main`.
- Loom client launched `minecraft_golf 0.8.5` and rendered (OpenGL); narrator `flite`
  warning is an environment issue unrelated to the mod.
- Docker dev server loaded `biome-golf-0.8.5.jar`, initialized, `Done`.
- Installed-client JAR deployed and SHA-256 matched the build artifact.

## Remaining Boundary

Manual playtest of meter feel: confirm repeated dead-centre timings land dead centre,
in-zone clicks fly straight, and out-of-zone misses still fan. The logic is proven by
unit tests; only perceived timing feel is unverified.
